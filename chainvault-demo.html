Blockchain-based secure file sharing — client-side prototype

🔐 Vault

Files are AES‑256 encrypted locally, then addressed by content hash — like IPFS.

Click or drop a file to encrypt & upload

Never leaves your device unencrypted. Key is wrapped for you (the owner) with RSA‑OAEP.

📒 Immutable Ledger

Every upload, share, revoke & access attempt is chained by hash.
How this prototype implements the proposal

Off-chain storage

Encrypted file bytes are kept in a mock content-addressed store, keyed by SHA‑256 of the ciphertext — simulating IPFS.

On-chain metadata

Only hashes, CIDs, owners and permission events are written to the ledger — never raw content.

Key-wrapped access control

Each file's AES key is wrapped with every authorized user's RSA‑OAEP public key. Revoking access deletes their wrapped copy.

Tamper evidence

Blocks are hash-linked to their predecessor, and AES‑GCM authentication rejects any modified ciphertext on decrypt.
